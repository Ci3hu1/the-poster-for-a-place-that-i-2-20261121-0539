VITRAEL — The Glass Desert: a travel poster for a place that isn't there. One glass spire over rippled glass dunes at golden hour, a lone traveller walking toward it.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR`, `/output`, or the working directory — first location that succeeds. Pure Python standard library; the poster is bundled as `entry.png` (rendered at build time by `render_poster.py`).
